# Repo docs builder

A docs folder without an index is a pile. This builds the tree.

## What lands

- A README at every level that names what is in the folder and links down into it.
- An up-link at the bottom of every page back to its parent index.
- One house style across all of them, so a reader stops noticing the format.

## What does not

No diagrams unless a diagram carries something prose cannot. No badges below the top
level. No page that exists only to link to one other page.
