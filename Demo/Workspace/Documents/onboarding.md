# Onboarding

Day one is reading, not writing. Nobody merges on day one and that is not a hazing
ritual — the conventions here are load-bearing and most of them are not obvious from the
code.

## Read in this order

1. The workspace README for whichever workspace you have been pointed at.
2. That workspace's `Agents/` README — the checks listed there are the ones CI runs.
3. The decision records. They are short and they explain most of the "why is it like
   this" questions before you have to ask them.

## Then

Pick something from the draft folder. It has no remote, no CI and no reviewers waiting,
which makes it the safest place to be wrong.
