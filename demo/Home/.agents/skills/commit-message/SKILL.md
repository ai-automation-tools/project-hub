# Commit message

Read the last twenty subjects in this repo before writing one. Whatever they do, do that.

## If the repo has no style

Imperative subject, under 72 characters, no trailing period. Body only when the *why* is
not obvious from the diff — and then the body is why, never what.

## Never

No scope prefixes the repo does not already use. No emoji unless the log is already full
of them. No "various fixes".
