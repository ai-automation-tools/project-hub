# Writing style

For documentation in this workspace. Not a style guide for product copy.

## Rules

- Lead with what the thing does. The reader already knows they are in a docs folder.
- State the limitation in the same paragraph as the feature, not in a caveats section
  at the bottom that nobody reaches.
- Tables for anything with more than three parallel facts. Prose for reasoning.
- No "simply", no "just", no "obviously". If it were obvious the page would not exist.

## Length

A page that needs a table of contents is two pages.
