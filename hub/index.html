Appearance

Tabs

On: right-click a file, bookmark or tab to open it in a new tab. Off: the hub shows one document at a time.

Off: links open in a new browser tab. On: they open in tabs inside the hub. Sites that refuse to be embedded still open in a browser tab, and Ctrl+click or a middle click always does.

Favorites

Scan depth

Choose how many folder levels to index (1–32). The default is 10. Larger values include deeper files and take longer to scan. Saved on this computer for all browsers using this hub.

Folders

Folders shown in the Explorer next to Projects. Adding or removing one updates hub.config.json and the sidebar at once; nothing on disk is moved or deleted.

Folders can only be added or removed on the computer running the hub.

Folder icons

Give a top-level folder in the Explorer an icon from the Material Icon Theme folder set VS Code uses. Saved in hub.config.json.

Folder icons can only be changed on the computer running the hub.

Sidebar

Backup

One file with everything you have set up: bookmarks, recent documents, theme and layout from this browser, plus the hub’s folders, folder icons, scan depth and favorites. Import it into another hub or browser to bring it all across. Bookmarks, recent documents and favorites are added to what is already there; other settings are replaced. The file lists folder paths from this computer.
